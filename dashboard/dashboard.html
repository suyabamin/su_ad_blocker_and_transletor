Core Principles

  • Zero Telemetry: No tracking, no user identifiers, no analytics, no third-party network calls.
  • Zero Cloud Translation APIs: Translations run locally in your browser. Your selected text is never uploaded.
  • Dedicated Offline PDF Reader: Bundled Mozilla PDF.js viewer with selection translation.
  • Declarative Net Request: High-performance native Chrome network filtering.
