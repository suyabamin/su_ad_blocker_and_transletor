# Su_AdBlock — Architecture & Data Flow

## 1. Overview
Su_AdBlock is built on Chrome Manifest V3 using vanilla JavaScript, HTML5, and CSS3. It combines native network-level request blocking (via Chrome Declarative Net Request) with an offline-capable English-to-Bangla translation subsystem and an extension-owned local PDF.js reader.

## 2. Component Breakdown

### A. Background Service Worker (`background/service-worker.js`)
- **Lifecycle & Persistence:** Restart-safe design. Core managers load state on wake-up from `chrome.storage.local`.
- **Message Router (`background/message-router.js`):** Enforces strict action validation and payload type checking.
- **Context Menus (`background/context-menu.js`):** Integrates Chrome's native right-click `Translate selection to বাংলা`. Gracefully handles internal `chrome://` URLs by opening the translation workbench in the dashboard.
- **Commands (`background/commands.js`):** Handles keyboard shortcuts (`Alt+Shift+B` for translation, `Alt+Shift+P` for ad-blocking toggle).

### B. Declarative Net Request (DNR) Subsystem
- **Static Rulesets:**
  - `rules/ads.json`: Baseline network ad blocking (Deterministic IDs: `1000 - 9999`).
  - `rules/trackers.json`: Analytics and tracking pixel blocking (Deterministic IDs: `10000 - 19999`).
  - `rules/annoyances.json`: Anti-adblock and annoyance script endpoints (Deterministic IDs: `20000 - 29999`).
- **Dynamic Rules:**
  - Custom user rules: Managed by `CustomRulesManager` (Deterministic IDs: `100000 - 199999`).
  - Allowlist exception rules: Generated by `WhitelistManager` (Deterministic IDs: `200000 - 299999`, `priority: 2`, action: `allowAllRequests`).
- **Feedback & Counters:** Uses `chrome.declarativeNetRequest.onRuleMatchedDebug` where permitted by developer mode; safely categorizes counts into session and all-time aggregate storage.

### C. Content Scripts & Cosmetic Filtering
- **Text Selection (`content/selection.js`, `selection.css`):**
  - Listens to `mouseup` events without interfering with textareas, inputs, or contenteditable fields.
  - Displays a high-z-index floating badge `Translate to বাংলা` with green shield icon.
  - Translation begins strictly upon user click.
  - Dialog provides original preview, Bengali translation, Copy button, and direct link to dashboard.
- **Cosmetic Engine (`content/cosmetic.js`, `cosmetic.css`):**
  - Reads global and domain-specific selectors from `cosmetic/selectors.json`.
  - Injects scoped hiding stylesheets into the DOM.
  - Employs a debounced (500ms) `MutationObserver` to clean up dynamically inserted ad containers while preserving host page responsiveness.

### D. Translation Subsystem
- **Lexicon Engine (`translator/lexicon.js`):** Hundreds of common English terms, technical words, verbs, pronouns, and numbers mapped to Bengali. Operates 100% offline with zero latency.
- **Neural Model Loader (`translator/model-loader.js`):** Integrates locally bundled `transformers.min.js` (Hugging Face / Xenova) and supports `Xenova/opus-mt-en-bn`. Manages WebAssembly and WebGPU initialization, download progress tracking, and offline persistence via Cache API.
- **Text Chunker (`translator/text-chunker.js`):** Natural boundary splitting preserving sentence structures and paragraph breaks.
- **Translation History:** Opt-in, strictly local, limited to 100 items by default, individually deletable.

### E. Dedicated PDF.js Reader (`translator/pdf-reader/`)
- Fully extension-owned page bundling Mozilla PDF.js v3.11.174 (`pdf.min.js`, `pdf.worker.min.js`).
- Renders local PDF documents directly in browser memory without sending bytes over any network.
- Text layer enables mouse selection and translation inside the built-in translation sidebar.

## 3. Storage Schema
All persistent user data is stored strictly in `chrome.storage.local`:
- `settings`: Master toggles, active rulesets, theme, history opt-in flag.
- `whitelist`: Array of clean domain strings.
- `customRules`: Array of user-defined filter objects.
- `statistics`: Local aggregate counts `{ allTime: {...}, session: {...} }`. Full URLs are never saved.
- `translationHistory`: Opt-in local translation entries `{ id, timestamp, original, translation, engine }`.
